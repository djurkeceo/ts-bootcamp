## 🏠 Domaći Zadatak #8

Napravi mini aplikaciju u `App.tsx`:

1. Prikaži listu od 3 zadatka — iskoristi `Zadatak` interface iz prethodnog projekta

2. Napravi komponentu `KarticaZadatka` koja prima jedan `Zadatak` kao prop i prikazuje ga

3. Dodaj `useState` koji prati **aktivni filter** (`"svi"` | `StatusZadatka`) — početna vrednost je `"svi"`

4. Prikaži dugmad za filter — kada se klikne, menja se `useState` vrednost i lista se filtrira

**Hint za strukturu:**
```
src/
├── App.tsx           ← glavna komponenta, state, filtriranje
├── components/
│   └── KarticaZadatka.tsx  ← komponenta za prikaz jednog zadatka
└── types.ts          ← svi interfejsi i tipovi
```

Ovo je prvi put da koristiš više fajlova u Reactu — istraži kako funkcioniše `import/export`! 💪
