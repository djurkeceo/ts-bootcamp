Prvo, napravi novi Vite projekat sa React + TypeScript templateom:

```bash
npm create vite@latest react-zadaci -- --template react-ts
cd react-zadaci
npm install
npm run dev
```

Kada se pokrene u browseru, istraži strukturu projekta i odgovori na ova pitanja pre nego što krenemo da pišemo kod:

1. Po čemu se razlikuje ovaj projekat od `vanilla-ts` projekta koji si pravio ranije? Šta je novo?
2. Šta je `App.tsx` — zašto `.tsx` ekstenzija umesto `.ts`?
3. Otvori `src/App.tsx` i pogledaj kod — šta primećuješ? Izgleda li ti poznato nešto?
