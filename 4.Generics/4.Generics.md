# Lekcija 4 — Generics 🧬

Naučio si dovoljno da razumeš **generics** — najmoćniju funkcionalnost TypeScripta.

Problem koji generics rešavaju:

```bash
// Imaš funkciju koja vraća prvi element niza
// Kako je tipizirati da radi za BILO koji tip?

// ❌ Opcija 1 — gubiš type safety
function prvi(niz: any[]): any {
  return niz[0];
}
const rezultat = prvi([1, 2, 3]); // rezultat je any — TS ne zna da je number

// ❌ Opcija 2 — pišeš istu funkciju više puta
function prviString(niz: string[]): string { return niz[0]; }
function prviNumber(niz: number[]): number { return niz[0]; }

// ✅ Opcija 3 — Generic funkcija
function prvi<T>(niz: T[]): T {
  return niz[0];
}
// T je "tip placeholder" — TS ga popunjava automatski
const broj = prvi([1, 2, 3]);      // T je number, rezultat je number
const tekst = prvi(["a", "b"]);    // T je string, rezultat je string
```
