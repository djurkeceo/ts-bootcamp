## Lekcija 3 — Functions & Enums 🔧

Sad kada znaš kako da tipiziraš podatke, vreme je za funkcije i enumove.

### Tipiziranje funkcija

```typescript
// Svaki parametar dobija tip, i povratna vrednost funkcije takođe
function saberi(a: number, b: number): number {
  return a + b;
}

// Opcioni parametar — mora biti NA KRAJU
function pozdrav(ime: string, uzvik?: boolean): string {
  if (uzvik) return `Zdravo, ${ime.toUpperCase()}!`;
  return `Zdravo, ${ime}.`;
}

pozdrav("Marko");        // ✅
pozdrav("Marko", true);  // ✅

// Default vrednost — ako se ne prosledi, koristi default
function napraviPost(
  naslov: string,
  status: StatusObjaveType = "draft"
): BlogPost {
  // ...
}
```

### Šta je `void`?

```typescript
// Kada funkcija NE vraća ništa — koristiš void
function ispisi(poruka: string): void {
  console.log(poruka);
  // nema return — void to komunicira
}

// Razlika između void i undefined:
// void = "ova funkcija ne treba da vrati ništa korisno"
// undefined = "ova funkcija može eksplicitno vratiti undefined"
```

### Enums — kada ih koristiti?

```typescript
// Do sada smo koristili string literal union:
type StatusObjaveType = "draft" | "published" | "archived";

// Enum je alternativa — ima prednosti i mane
enum StatusObjave {
  Draft = "draft",
  Published = "published",
  Archived = "archived"
}

// Korišćenje:
const status = StatusObjave.Published; // vrednost je "published"

// Prednost enuma — autocompletion i refactoring
// Mana — generiše više JS koda od union tipa

// 💡 Moderni TS projekti često preferiraju union type nad enumom
// Enum ima smisla kada imaš 6+ vrednosti ili deliš tip između više fajlova
```
