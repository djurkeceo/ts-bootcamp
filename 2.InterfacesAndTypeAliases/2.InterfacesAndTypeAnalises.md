## Lekcija 2 — Interfaces & Type Aliases 🏗️

Sada kada znaš primitive, vreme je za pravu moć TS-a. Zamisti da modeluješ korisnika:
```Bash

// ❌ Ovako bi u JS radio — nikakva struktura
const korisnik = {
  ime: "Marko",
  godine: 25,
  email: "marko@gmail.com"
};

// ✅ U TS-u, definišeš "oblik" objekta unapred
interface Korisnik {
  ime: string;
  godine: number;
  email: string;
  avatar?: string; // ? znači OPCIONO — može biti string ili undefined
}

// Sada TS zna šta Korisnik mora imati
const marko: Korisnik = {
  ime: "Marko",
  godine: 25,
  email: "marko@gmail.com"
  // avatar nije obavezan, može se izostaviti
};

marko.telefon = "064..."; // 🔴 Greška! 'telefon' ne postoji na tipu Korisnik
```
### Interface vs type — večito pitanje ❓
```Bash

// Interface — za oblike objekata, može se "proširiti"
interface Vozilo {
  marka: string;
  brzina: number;
}

interface Automobil extends Vozilo { // nasleđuje od Vozilo
  brojVrata: number;
}

// Type alias — fleksibilniji, za sve ostalo
type ID = string | number;           // union types
type Koordinate = [number, number];  // tuple
type Callback = () => void;          // funkcija

// Type može i objekte, slično kao interface:
type Proizvod = {
  naziv: string;
  cena: number;
};
```

Praktično pravilo: Koristi interface za objekte/klase, type za sve ostalo.
