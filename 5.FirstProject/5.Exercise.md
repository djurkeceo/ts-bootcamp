# 🏠 Domaći Zadatak #5

Podesi prvi pravi projekat:

```bash
npm create vite@latest moj-prvi-projekat -- --template vanilla-ts
cd moj-prvi-projekat
npm install
npm run dev
```

Kada pokreneš, istraži strukturu i odgovori na ova pitanja:

1. Šta je `vite.config.ts` i čemu služi?
2. Koja je razlika između `dependencies` i `devDependencies` u `package.json`?
3. Zašto `node_modules` folder nikad ne commitujemo u Git?
