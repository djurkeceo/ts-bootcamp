# OOP u TypeScriptu — Lekcija 1: Klase

## Šta je klasa?

Znaš već `interface` — opisuje **oblik** objekta. Klasa je korak dalje — opisuje oblik **i** ponašanje objekta.

```typescript
// Interface — samo struktura
interface Auto {
    marka: string;
    brzina: number;
}

// Klasa — struktura + metode + logika
class Auto {
    marka: string;
    brzina: number;

    constructor(marka: string) {
        this.marka = marka;
        this.brzina = 0;
    }

    ubrzaj(za: number): void {
        this.brzina += za;
    }

    zakoci(): void {
        this.brzina = 0;
    }
}

const mojeAuto = new Auto('BMW');
mojeAuto.ubrzaj(50);
console.log(mojeAuto.brzina); // 50
mojeAuto.zakoci();
console.log(mojeAuto.brzina); // 0
```

### Ključni pojmovi

- `constructor` — poziva se kada kreiraš novi objekat sa `new`
- `this` — referenca na trenutni objekat
- **metode** — funkcije koje pripadaju klasi

## Access Modifiers — `public`, `private`, `protected`

Access modifiers kontrolišu ko može da pristupi poljima i metodama klase.

```typescript
class BankovniRacun {
    public vlasnik: string;      // dostupno svuda
    private stanje: number;      // dostupno SAMO unutar klase

    constructor(vlasnik: string, pocetnoStanje: number) {
        this.vlasnik = vlasnik;
        this.stanje = pocetnoStanje;
    }

    public uplati(iznos: number): void {
        this.stanje += iznos;
    }

    public getStanje(): number {
        return this.stanje;
    }
}

const racun = new BankovniRacun('Djurke', 1000);
racun.uplati(500);
console.log(racun.getStanje()); // 1500
console.log(racun.stanje);      // 🔴 Greška! stanje je private
```

### Pregled access modifiers

| Modifier | Dostupno u klasi | Dostupno u podklasi | Dostupno svuda |
|---|---|---|---|
| `public` | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ❌ |
| `private` | ✅ | ❌ | ❌ |

### Skraćena sintaksa u constructoru

TypeScript ima skraćenu sintaksu — umesto da pišeš polje i `this.x = x` odvojeno:

```typescript
// Duža sintaksa
class Osoba {
    public ime: string;
    private godine: number;

    constructor(ime: string, godine: number) {
        this.ime = ime;
        this.godine = godine;
    }
}

// Kraća sintaksa — isti rezultat
class Osoba {
    constructor(
        public ime: string,
        private godine: number
    ) {}
}
```
