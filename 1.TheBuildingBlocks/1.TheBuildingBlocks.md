## 📘 Lekcija 1: Zašto TypeScript uopšte postoji?

JavaScript je **dynamically typed** jezik. To znači da JS ne proverava tipove dok pišeš kod — greška se pojavi tek u toku izvršavanja (**runtime error**).

### ❌ Problem: Čist JavaScript
Greška se ne vidi dok ne pokreneš sajt ili aplikaciju.

```bash
// JavaScript primer (potencijalni krah)
function pozdrav(ime) {
  return "Zdravo, " + ime.toUpperCase();
}

pozdrav(42); // 💥 Runtime Error: ime.toUpperCase is not a function
```
```bash
// TypeScript primer (siguran kod)
function pozdrav(ime: string): string {
  return "Zdravo, " + ime.toUpperCase();
}

pozdrav(42); // 🔴 Editor odmah javlja: Argument of type 'number' is not assignable to parameter of type 'string'
```

## 🧱 Lekcija 2: Primitivni tipovi (The Building Blocks)
U TypeScript-u, svaka vrednost ima svoj tip. To je ono što nam omogućava sigurnost i predvidljivost koda. Krećemo od samih osnova:

---

### 1. Osnovne varijable 📍
Najčešće korišćeni tipovi koje ćeš sretati u svakodnevnom radu.
```bash
let ime: string = "Marko";
let godine: number = 25;        // Nema int/float razlike (kao u C#) — samo number
let jeAktivan: boolean = true;
```

### 2. Nizovi (Arrays) 📚
```bash
let gradovi: string[] = ["Beograd", "Novi Sad", "Niš"];
let ocene: number[] = [8, 9, 10];

// Alternativna sintaksa (Generic format)
let tagovi: Array<string> = ["typescript", "javascript"];
```

### 3. Moćne TS funkcionalnosti ⚡
Ovo su "supermoći" koje čine TypeScript superiornim u odnosu na običan JavaScript:

#### 🧪 Union Types
Vrednost može biti jedan od više ponuđenih tipova. Savršeno za situacije gde ID može biti i broj i string.
```bash
let id: string | number = "abc-123";
id = 456; // ✅ OK — oba su dozvoljena
```
#### 🎯 Literal Types
Vrednost mora biti tačno definisan string ili broj. Ovo je kao "mini-enum".
```bash
let smer: "levo" | "desno" | "gore" | "dole" = "levo";
smer = "dijagonalno"; // 🔴 Greška!
```

#### 📍 Tuple
Specijalan niz sa fiksiranim brojem elemenata i preciznim redosledom tipova.
```bash
let koordinate: [number, number] = [44.8, 20.5]; // [latitude, longitude]
```
### 🧠 Ključni koncept: Type Inference
TypeScript je često pametniji nego što mislimo. On može sam da zaključi tip varijable na osnovu njene početne vrednosti, čak i ako ga mi ne napišemo.
```bash
let grad = "Beograd"; // TS automatski zna da je ovo 'string'
let broj = 42;        // TS automatski zna da je 'number'

grad = 100; // 🔴 Greška! TS ne dozvoljava promenu tipa nakon što ga zaključi
```
